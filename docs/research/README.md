# Research notes

Working notes for directions on the [roadmap](../../ROADMAP.md) that aren't
built yet: what we looked into, what we found, what we decided, and what's
still open. They keep research from getting lost between sessions.

## How they work

- **One note per direction**, named after it (`timber-structures.md`).
- **Write it while researching.** Findings get a source link and a date;
  prices and anything else that goes stale say when they were checked.
- **Decisions are marked as decisions**, so the next session doesn't argue
  them again. Open questions stay open until someone answers them.
- **When the feature ships, the note goes.** Lasting decisions move to where
  they're used (the skill, `processes.md`, code comments, the changelog),
  then the note is deleted. Git history keeps the full research.

## Template

```
# <Direction>

Status: researching | decided, not started | in progress
Last updated: YYYY-MM-DD

## The question
## Findings          (with sources and dates)
## Decisions         (what we chose, and why)
## Open questions
```
